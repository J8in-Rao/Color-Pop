# Color Pop! 🎨

*The most addicting color-matching game this side of a Monday morning!*

---

## What is this thing? 🤔

So you know how sometimes you're just sitting there, staring at your computer screen, wondering if you have what it takes to be a professional color matcher? Well, wonder no more! Color Pop is here to answer that burning question.

It's a simple game where you have to find and click on squares of a specific color before time runs out. Sounds easy, right? WRONG! The timer keeps getting faster with each round, and before you know it, you're frantically clicking like a caffeinated squirrel!

## Features ✨

- **Colorful Chaos**: 6 different colors to confuse your brain
- **Speedy Rounds**: Timer decreases each round (because we like to watch you struggle)
- **Addictive Gameplay**: Just one more round... and another... and another...
- **Minimalist Design**: Because we're not here to distract you from the real challenge
- **No Fancy Frameworks**: Just good ol' HTML, CSS, and JavaScript (like your CS professor taught you)

## How to Play 🎮

1. Click the "Start" button (I know, it's revolutionary)
2. Find the 3 squares that match the color shown at the top
3. Click them before time runs out
4. Try not to scream when the timer speeds up
5. Get a high score and impress your friends (or at least your cat)

## Installation 🛠️

You don't need to install anything! This bad boy runs right in your browser. Just open `index.html` and you're good to go.

But if you're feeling fancy and want to serve it properly:

```bash
# Clone this repository
git clone https://github.com/J8in-Rao/Color-Pop.git

# Navigate to the directory
cd Color-Pop

# Serve with your favorite server (or just double-click index.html)
# For example, with Python 3:
python -m http.server 8000
```
